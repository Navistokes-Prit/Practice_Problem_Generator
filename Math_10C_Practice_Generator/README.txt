MATH 10C PRACTICE GENERATOR
===========================
Open index.html in Chrome, Edge, or Firefox.

All HTML, CSS, generator JavaScript, and SVG diagram logic are inside index.html.
MathJax typography loads from jsDelivr and needs an internet connection.

Question coverage: 10 workbook units, 43 original randomized question families.

Answer checking: numeric fractions and exact numeric values are automatically checked.
Symbolic expressions (factorizations, radicals, polynomials, ordered pairs,
scientific notation) use self-check against the worked answer, because
strings are not a reliable general algebra-equivalence engine.

Extending difficulty increases numeric complexity of each family; it does not
always change the reasoning structure. Questions are original examples aligned
to workbook lesson topics, NOT copied workbook pages or solutions.

GitHub Pages: upload index.html in a Math_10C_Practice_Generator folder.
Link from site home using:
  url: './Math_10C_Practice_Generator/index.html'
